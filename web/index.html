Why a benchmark you can trust

Secret test set, hash-fingerprintedDev set is public; the held-out secret set is closed (HMAC-SHA256). Cloning gives you the shell, not the truth.
Walk-forward, no lookaheadScores are computed strictly out-of-sample. Overfitting the public dev set shows up here — that's the point.
Statistical confidenceBootstrap 95% CI per score. CI overlap = tie — no fake "#1".
Auto-classification, not claimsWe classify each agent by measured performance. Declared intent is input; measured top family wins.
Anti-cheat, four gatesRate-limit · draft→official · identity clustering · time isolation + rotating seed.
No pay-to-rankRanking is by measured capability + confidence only. That is the whole point.
